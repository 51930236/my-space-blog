# hexo-blog-vue 项目交接文档

## 1. 项目简介

`hexo-blog-vue` 是一个基于 Vue 3 + Vite 构建的博客前台 + 后台管理系统，参考 Hexo 主题 `hexo-theme-redefine` 的样式与交互。

项目已与同仓库下的 NestJS 后端 `hexo-serve`（Prisma + MySQL）完成对接，前后端通过 RESTful API 交互。后端启动时会读取 `src/posts/` 目录下的 Markdown 文件初始化文章数据；前台文章列表、详情以及后台管理功能均优先调用后端接口获取数据。部分运行时配置（如站点设置）仍保留 `localStorage` 覆盖层作为前端缓存。

## 2. 技术栈

| --------- | ------------------------------------------ |
| 框架      | Vue 3（Composition API +`<script setup>`） |
| 构建工具  | Vite 8                                     |
| 路由      | Vue Router 4                               |
| 状态管理  | Pinia 4                                    |
| 语言      | TypeScript 6                               |
| 样式      | Tailwind CSS v4（主）+ SCSS（辅）          |
| UI 组件库 | Element Plus（已引入，按需使用）           |
| 图表      | ECharts（按需使用）                        |

### 后端（`hexo-serve`）

| 层级   | 技术                                       |
| ------ | ------------------------------------------ |
| 框架   | NestJS 11                                  |
| ORM    | Prisma 5.22.0                              |
| 数据库 | MySQL 8                                    |
| 鉴权   | JWT + Passport                             |
| 权限   | RBAC（Role / Permission / RolePermission） |

### 通用

| 层级     | 技术                       |
| -------- | -------------------------- |
| 图标     | Font Awesome Free          |
| 包管理   | pnpm                       |
| 代码规范 | ESLint + Prettier + oxlint |

### Tailwind CSS v4 注意事项

- 入口文件使用 `@import "tailwindcss"`，不要使用 v3 的 `@tailwind base/components/utilities` 指令。
- Vite 配置中已加入 `@tailwindcss/vite` 插件。
- PostCSS 配置简化为 `{ plugins: {} }`。
- Tailwind v4 的 CSS 优先级较低，必要时使用 `!` 修饰符覆盖冲突样式。

## 4. 关键配置说明

### 4.1 站点配置 `src/data/config.ts`

对应 `hexo-theme-redefine` 的 `_config.yml`，包含：

- `info`：站点标题、副标题、作者、头像、favicon
- `colors`：主题色、默认模式
- `global`：字体、内容最大宽度、侧边栏宽度、hover 效果、滚动进度条
- `navbar`：导航栏链接（支持二级下拉菜单）、搜索开关
- `homeBanner`：首页横幅图片、标题、打字机字幕
- `home.sidebar`：首页侧边栏配置

## 5. 状态管理

### `useArticlesStore`（`src/stores/articles.ts`）

- `articles`：全部文章列表，默认通过 `/api/articles` 从后端获取，`content` 为 Markdown 原文
- `tags` / `categories`：标签/分类数据，通过 `/api/tags`、`/api/categories` 获取
- `getArticlesByPage(page, pageSize)`：分页获取文章
- `getArticlesByTag(tag)` / `getArticlesByCategory(category)`：按标签/分类筛选
- `searchArticles(keyword)`：关键词搜索
- `getArticleBySlug(slug)`：根据 slug 获取文章
- `createArticle` / `updateArticle` / `deleteArticle`：文章 CRUD（调用后端接口）
- `createTag` / `updateTag` / `deleteTag`：标签 CRUD
- `createCategory` / `updateCategory` / `deleteCategory`：分类 CRUD（支持父子层级）

### `useConfigStore`（`src/stores/config.ts`）

读取 `src/data/config.ts` 中的 `siteConfig`，提供导航栏、横幅、侧边栏、页脚、评论等配置的计算属性。

### `useSiteSettingsStore`（`src/stores/siteSettings.ts`）

后台站点设置的 `localStorage` 覆盖层。用户通过后台修改的配置会合并到 `useConfigStore` 中，前台自动生效。

### `usePagesStore`（`src/stores/pages.ts`）

自定义页面管理，支持页面 CRUD，数据持久化到 `localStorage`。

### `useBookmarksStore`（`src/stores/bookmarks.ts`）

书签分类与链接管理，前台 [BookmarksView.vue](file:///e:/Learning/新建文件夹/hexo-blog-vue/src/views/frontend/BookmarksView.vue) 也依赖此 store。

### `useMediaStore`（`src/stores/media.ts`）

媒体库状态，管理上传的图片列表，持久化到 `localStorage`。

### `useUsersStore`（`src/stores/users.ts`）

用户管理状态，通过 `/api/users` 接口进行 CRUD，支持为每个用户分配角色。

### `useAdminStore`（`src/stores/admin.ts`）

管理员登录态，调用后端 `/api/auth/login` 获取 JWT `accessToken` 与当前用户信息，token 写入 `localStorage`。用户对象包含 `role`（角色）与 `permissions`（权限码列表），并提供 `hasPermission(code)` 方法用于前端权限判断。

### `useThemeStore`（`src/stores/theme.ts`）

负责暗黑/亮色模式切换与持久化。

## 6. 样式方案

- **全局变量**：`src/assets/styles/tailwind.css` 中定义 CSS 变量，如 `--navbar-height: 70px`。
- **SCSS 变量**：`src/assets/styles/variables.scss` 中保留部分 SCSS 变量供组件内使用。
- **组件样式**：优先使用 Tailwind 工具类；复杂样式或需要嵌套时使用 `<style scoped lang="scss">`。
- **主题变量**：颜色、阴影等通过 CSS 变量跟随 `html.dark` 切换。

## 7. 开发规范

1. 使用 `pnpm` 作为包管理工具。
2. 单个代码文件原则上不超过 300 行，复杂模块应拆分。
3. 优先使用 Tailwind CSS，SCSS 作为辅助。
4. Vue 组件使用 `<script setup lang="ts">` + Composition API。
5. 组件名使用 PascalCase，文件路径使用 camelCase 或 kebab-case。
6. 类型定义统一放在 `src/types/` 目录。
7. 通用逻辑抽取到 `src/composables/`。

## 9. 常见问题与注意事项

1. **图标不显示**：检查 Font Awesome 图标前缀是否为 `fa-solid`，免费版中很多图标只有 solid 样式。
2. **Tailwind 类不生效**：确认没有使用 v3 的 `@tailwind` 指令，且 Vite 插件已正确配置；优先使用 Tailwind v4 规范类名，如 `h-75`、`wrap-break-word`。
3. **首页分页不滚动**：检查 `router/index.ts` 的 `scrollBehavior` 是否保留了 `query.page` 特殊处理。
4. **后台站点设置修改后刷新不生效**：站点设置的运行时覆盖层保存到 `localStorage`，若需要恢复默认配置，可清除浏览器 `localStorage` 中对应 key。
5. **文章数据从哪来**：后端启动时读取 `src/posts/*.md` 初始化到数据库；前台与后台文章列表均通过 `/api/articles` 获取。若 `.md` 文件有更新，需要重启后端或重新执行 seed。
6. **对接后端 API**：建议保留现有 store 结构，优先替换 `src/utils/postLoader.ts` 中的加载函数；文章/页面等内容接口返回 Markdown 原文，前台统一用 `marked` 解析。
